# FIFA World Cup 2026 – Player Dataset

A structured dataset of all players selected for the FIFA World Cup 2026.

## Contents
| Column | Description |
|---|---|
| TEAM | National team (FIFA name) |
| POS | Position (GK / DF / MF / FW) |
| PLAYER NAME | Full name |
| FIRST NAME(S) | Given name(s) |
| LAST NAME(S) | Family name(s) |
| NAME ON SHIRT | Name printed on jersey |
| DOB | Date of birth (DD/MM/YYYY) |
| CLUB | Club team and country |
| HEIGHT (CM) | Height in centimetres |

## Coverage
- 48 teams / 1248 players
- Data collected: 2026-09-10
- Source: [FIFA](https://fdp.fifa.org/assetspublic/ce281/pdf/SquadLists-English.pdf)
